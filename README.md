# Simple-FC
A RP2350 based flight controller with a 10-axis IMU

## Overview
- **MCU**: RP2350
- **Gyroscope/Accelerometer**: LSM6DSM
- **Magnetometer**: MMC5983MA
- **Barometer**: BMP384
- **External Storage**: Micro SD card
- **MCU Storage**: 16MB
- **Input Voltage**: 1.2V-5.3V
- **I/O**: 
    - 4 PWM
    - 2 UART
    - 2 I2C
